## 5. Bug found and fixed during setup (worth remembering)

**`internal.is_contactable(p_dot, p_channel contact_channel)`** compared
`contact_suppressions.channel` (type `suppression_channel`, which has an extra `'all'` value) directly
against `p_channel` (type `contact_channel`) with `cs.channel in (p_channel, 'all')`. Postgres has no
`suppression_channel = contact_channel` operator, so the function failed to create:

```
ERROR: 42883: operator does not exist: suppression_channel = contact_channel
```

**Fix:** cast both sides to `text` — `cs.channel::text in (p_channel::text, 'all')` — since every
`contact_channel` value is a valid `suppression_channel` value. Fixed at both call sites in
`supabase/migrations/20260720001100_rpc.sql`, committed (`8d70c57`), verified with a headless
clipboard test on the regenerated setup page before sending Hunter the corrected link. This is
exactly the kind of bug a live `supabase db reset` was always going to catch that static review
couldn't — no further action needed, just noted here so the next person doesn't reintroduce it.

## 8. Known tech debt to deliberately address (not urgent, but tracked)

From the round-5 audit's codebase sweep (`06-ux-audit.md` §8, "Codebase quick-wins" +
"techDebt"), the single biggest one:

**The production app scaffold and `02-frontend-spec.md` still encode the pre-lock "orange accent +
dark mode" direction** (`app/src/theme/tokens.css` ships `#e8611d` orange plus a full dark-mode
implementation and `ThemeProvider` toggle). The **TNBS Design System v1.0** (navy-only, light-only)
was locked one day *after* those files were written, and only the mockup was brought forward to
match it. This needs a **deliberate reconciliation pass** — not a find-replace hex swap, since
there's live dark-mode plumbing (`ThemeProvider`, the dark `@media`/`[data-theme=dark]` blocks) to
actually remove — **before M3 builds real chrome on top of these tokens.**

`pipeline/src/facets.ts` to read the now-existing `pipeline_config` table instead of its hardcoded
constant, prune the unreachable Dossier/Ledger mockup profile variants, delete stale dark-mode
